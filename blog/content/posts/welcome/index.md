Welcome! This blog is built with [Hugo](https://gohugo.io) and managed with [Nix](https://nixos.org).

## What to Expect

- Technical writing and tutorials
- Data analysis and visualizations
- Notes on tools and workflows

## The Stack

This site is rendered by Hugo and its dependencies are pinned via a Nix flake, so the build is fully reproducible.

```bash
# Enter the dev shell
nix develop

# Preview locally
hugo server

# Build the site
hugo
```
